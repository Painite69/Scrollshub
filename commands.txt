# ScrollsHub desktop — build & publish (Windows)

# One-time
gh auth login

# Every app update
# 1) Bump "version" in desktop/package.json (e.g. 0.1.3 -> 0.1.4)
# 2) Update DESKTOP_DOWNLOAD_URL in src/components/Header.tsx to match
# 3) Build + upload installer to GitHub Releases:
npm run dist:desktop
.\scripts\publish-desktop-release.ps1

# 4) Ship the site Download link (Cloudflare) — commit + push:
git add desktop/package.json src/components/Header.tsx commands.txt
git commit -m "Release desktop vX.Y.Z (Download link + installer notes)."
git push

# Notes
# - GitHub Release = installer + auto-update (latest.yml). Site only needs Header URL pushed.
# - Auto-update checks: ~8s after launch, every 30 min, and when you refocus the app.
# - Ctrl+R / F5 reloads the focused window.
